# 🛂 외교부 동행앱 등록 가이드

> 외교부 "해외안전여행 동행" 앱에 가족 4명 일정 등록. 사고·재난 발생 시 영사 콜센터가 위치 기반으로 연락·지원.

## 📌 정식 명칭

- 앱 이름: **해외안전여행 동행** (외교부 운영, 무료)
- iOS: App Store "해외안전여행 동행"
- Android: Play Store "해외안전여행 동행"
- 웹: https://www.0404.go.kr/dev/main.mofa

### 1. 앱 다운로드

- App Store / Play Store에서 "해외안전여행 동행" 검색 → 설치
- 외교부(Ministry of Foreign Affairs) 마크 확인

### 2. 회원가입 & 본인 인증

- 휴대폰 본인 인증 (한국 번호 SMS) 또는 PASS 앱 인증
- 이름·생년월일·여권번호 입력

### 3. 여행 등록

- "내 여행 등록" → "신규 등록"
- 출국일·귀국일 입력 (2026-05-20 / 2026-05-25)
- 방문 국가: 베트남 / 도시: 다낭 (Da Nang)
- 숙소 주소 2곳 입력 (영문)
- 여행 목적: 가족여행

### 4. 동행자 추가

- "동행자 추가" → 가족 3명 (배우자·자녀 2명)
- 자녀는 보호자(부모) 정보 자동 연결
- 각자 여권번호·이름(영문) 입력

### 5. 비상 연락처

- 국내 가족·지인 1명 (이름·관계·연락처)
- 사고 발생 시 외교부가 즉시 연락하는 번호

### 6. 위치 기반 알림 동의

- 백그라운드 위치 동의 ON (선택이지만 강력 권장)
- 다낭 지역 위기·재난·태풍 알림 자동 푸시

## ⚠️ 주의

- **D-7 권장**: 등록은 출국 1주일 전이 적당. 너무 일찍 등록하면 일정 변경 시 수정 번거로움.
- **여권번호 정확히**: 오타 1글자라도 영사 지원 시 신원 확인 지연. 여권 사진 보고 입력.
- **자녀 단독 등록 X**: 9세·5세는 반드시 부모 계정 동행자로 등록. 미성년자 단독 계정 불가.
- **위치 권한**: iOS는 "항상 허용" 선택해야 백그라운드 알림 작동. "앱 사용 중" 만 허용하면 재난 알림 못 받음.
- **귀국 후**: 자동 종료되지만 원하면 수동으로 "여행 종료" 처리 가능.
- **여행자 보험과 별개**: 동행앱은 외교부 영사 지원용. 의료비·도난은 별도 여행자보험 필수.
