## 🛕 2.1 린응 사원 (Linh Ung Pagoda / Chùa Linh Ứng)

> **베트남 최대 67m 해수관음상 — 다낭의 영적 랜드마크**

![린응사 전경](https://upload.wikimedia.org/wikipedia/commons/9/91/Linh_Ung_Pagoda.jpg)

🛕 손짜반도 중턱(해발 약 200m)에 자리 잡은 다낭의 영적 랜드마크. **30층 높이에 맞먹는 67m 해수관음상**이 다낭 만을 굽어보는데, 미케 비치에서도 또렷이 보일 정도. 2010년 완공된 비교적 새로운 사찰이라 동선이 깔끔하고 계단도 적당.

![미케 비치에서 본 린응사 해수관음상](https://upload.wikimedia.org/wikipedia/commons/thumb/3/3a/Linh_Ung_Pagoda_seen_from_My_Khe_Beach_1.jpg/960px-Linh_Ung_Pagoda_seen_from_My_Khe_Beach_1.jpg)

- 🌊 다낭 만 + 미케 비치 + 시내 한눈에 조망
- 📸 17m 8층 석탑·금빛 불상 = **사진 명소**
- 🌅 **늦은 오후 햇살**이 동상에 비치는 풍경 일품
- 🆓 **무료 입장** (주차 무료)

## 🪨 2.2 오행산 (Marble Mountains / Ngũ Hành Sơn)

> **5개 봉우리·동굴·계단 — 다낭 대표 산악 사찰**

![오행산에서 본 다낭 해안 전경 (2024)](https://upload.wikimedia.org/wikipedia/commons/thumb/7/72/Da_Nang_-_coastal_view_from_Marble_Mountains_Mar_2024_01.jpg/960px-Da_Nang_-_coastal_view_from_Marble_Mountains_Mar_2024_01.jpg)

🪨 5가지 원소(금·수·목·화·토)에서 이름 딴 5개 대리석 봉우리. 그중 가장 큰 **투이선(水山)**만 일반 개방. 산 안쪽에 후옌콩·탕쩐 등 거대 자연 동굴, 동굴 안에 사찰과 불상이 박혀 있어 **인디아나존스 분위기**. 2019년 국가특별유적 지정.

![오행산 부처상](https://upload.wikimedia.org/wikipedia/commons/thumb/b/bc/Buddha_Statue%2C_Marble_Mountain.jpg/960px-Buddha_Statue%2C_Marble_Mountain.jpg)

### 무엇이 매력인가
- 🪨 **거대 동굴 + 불상** = 5세도 압도되는 스케일
- 🛗 **엘리베이터 1.5만동** (편도) — 계단 회피 가능
- 🌊 정상 전망대에서 **논누억 비치 + 다낭 시내 파노라마**
- 🏛️ 후옌콩 동굴 = 대리석 천장에서 빛 떨어지는 신비 공간
- 💰 **입장 4만동(약 2,200원)** — 매우 저렴

| 🚐 미카즈키에서 | 차 30분 |

## ⛪ 2.3 다낭 핑크 성당 (Da Nang Cathedral / Nhà thờ Con Gà)

> **1923년 프랑스 식민지 시대 핑크 고딕 — 다낭 No.1 포토존**

![다낭 대성당 (핑크 성당) — Wikimedia](https://upload.wikimedia.org/wikipedia/commons/thumb/f/fe/Da_Nang_Cathedral_-_Da_Nang%2C_Vietnam_-_DSC02464.JPG/960px-Da_Nang_Cathedral_-_Da_Nang%2C_Vietnam_-_DSC02464.JPG)

⛪ 1923년 프랑스 신부 **루이 발레**가 설계, 단 한 해(1924)에 완공된 다낭 유일 식민지 시대 성당. **파스텔 핑크 외관 + 70m 종탑 + 풍향계 수탉**(현지명 "꽁가 = 닭 성당")이 시그니처. 시내 한복판 트란푸 거리에 위치, **다낭 인스타 인증샷 1순위**.

### 무엇이 매력인가
- 🌸 **파스텔 핑크 색감** = 인생샷·아오자이 인증샷 끝판왕
- ⛪ **고딕 양식 + 스테인드글라스** = 유럽 분위기
- 🐓 종탑 위 **풍향계 수탉** (높이 70m, "닭 성당" 별명)
- 🆓 **무료** + 시내 한복판 = 접근성 ◎
- 📸 5분이면 사진 끝, **시간 부담 0**

### 위치·이동·비용
| | |
|---|---|
| 📍 위치 | 156 Tran Phu, 시내 한복판 |
| 🚐 푸라마에서 | **차 12~15분** |
| 🚐 미카즈키에서 | 차 22분 |
| 💰 입장 | **무료** (외관만, 미사 시 내부) |
| 🕖 외부 관람 | 07:00~18:00 (상시) |
| 🕖 내부 입장 | 평일 오전 09:00 (관광객용) |
| ⏱️ 소요 | **15~30분** (사진 위주) |

### ⚠️ 베스트 시간대
| 시간 | 추천도 | 이유 |
|---|---|---|
| **평일 07:30~09:00** | ⭐⭐⭐⭐⭐ | **단체 관광객 X, 햇빛 부드러움** |

### 5세·9세에게는?
- ✅ **5분이면 사진 끝** = 5세 체력 부담 ❌
- ✅ 핑크색 = **여아 비주얼 호기심** 자극
- ✅ 평지·짧은 동선
- ⚠️ 한낮엔 햇볕 + 인파 → 짜증 유발

### 가족 적합도 ★★★★

- **15~30분 짧은 정차** = 일정에 끼우기 쉬움
- 무료 + 시내 + 평지 = 5세 부담 없음
- 9세·엄마 핑크 인생샷 = **사진 평생 소장**
- **참 박물관(2.4)·콩카페와 도보권**

**🟡 패스해도 되는 이유**
- 단순 외관 사진 = 여행지에서 "꼭" 필요한지 의문

## 🏛️ 2.4 참 박물관 (Cham Museum / Bảo tàng Điêu khắc Chăm)

> **참파 왕국 1500년 조각 컬렉션 — 세계 최대급**

![참 박물관 내부 조각 (Wikimedia)](https://upload.wikimedia.org/wikipedia/commons/thumb/7/74/Vietnam_-_Da_nang_-_Mus%C3%A9e_de_la_sculpture_Cham_%2822%29.JPG/960px-Vietnam_-_Da_nang_-_Mus%C3%A9e_de_la_sculpture_Cham_%2822%29.JPG)

🏛️ 1915년 프랑스 고고학자 **앙리 파르멍티에**가 설립, 1919년 첫 건물 완공. **세계 최대급 참파 조각 컬렉션** — 7~13세기 사암·테라코타·청동 유물 300점 이상. 미선(My Son) 유적지에서 옮겨온 진품도 다수. 노란색 식민지 건물 자체가 작품.

### 무엇이 매력인가
- 🏛️ **참파 왕국(2~17세기) 1500년 역사** 한 곳에서
- 🗿 **시바·압사라·드래곤 조각** = 인디아나존스 분위기
- ☀️ **에어컨** = 더위 회피 (5월 30℃+에서 결정적)
- 💰 **16세 미만 무료**, 성인 6만동(약 3,300원)
- 🇫🇷 노란색 식민지 건축 = 사진 배경 ◎

## 🛕 2.6 팝람 사원 (Phap Lam Pagoda / Chùa Pháp Lâm)

> **다낭 시내 한복판의 조용한 1934년 사찰**

![팝람사 부처상 (Wikimedia)](https://upload.wikimedia.org/wikipedia/commons/thumb/0/0e/Phap_Lam_Pagoda_statue.jpg/960px-Phap_Lam_Pagoda_statue.jpg)

🛕 1934년 안남 불교회가 세운 다낭 시내 한복판의 2층 사찰. 콘 시장에서 도보 5분. **다낭 불교회 본부**로 종교 활동의 중심지지만, **한국 관광객엔 거의 알려지지 않음**. 1층 강당(1000명 수용), 2층 본당에 11m 황금 석가모니불상.

### 무엇이 매력인가
- 🛕 **현지인 위주의 조용한 사찰** (관광지화 X)
- 🌳 **시내 한복판인데 정원과 보리수** — 도심 오아시스
- 🆓 **무료 입장** + 24시간 개방
- 🪷 11m 황금 석가모니불 + 마당 보살상 + 채식 식당 인근

### 위치·이동·비용

|---|---|

- ☀️ 한낮은 더위 ↑

- 부모 영적 휴식 = 가능
