## 🏮 5.1 마담란 (Madame Lân / Nhà hàng Madame Lân)

> **중부 정통 풀세트 + 한국어 사이트 + 강변 — "1순위" 결정 카드**

![베트남 반쎄오](https://upload.wikimedia.org/wikipedia/commons/thumb/c/c2/B%C3%A1nh_X%C3%A8o_in_Saigon_2.jpg/800px-B%C3%A1nh_X%C3%A8o_in_Saigon_2.jpg)

🥘 2012년 오픈한 한 강 강변의 콜로니얼풍 정통 베트남 요리 식당. 한국인이 가장 먼저 떠올리는 다낭 베트남식 No.1. **공식 한국어 사이트** 운영, 메뉴판도 한국어, 직원이 반쎄오 먹는 법까지 시연해 줌. **1층 야외 정원(나무 한그루)·2층 에어컨**이라 더위 회피 가능.

![베트남 반세오 / 짜조 풀세트](https://upload.wikimedia.org/wikipedia/commons/thumb/d/d3/B%C3%A1nh_x%C3%A8o_with_lettuce_wrap.jpg/800px-B%C3%A1nh_x%C3%A8o_with_lettuce_wrap.jpg)

### 무엇이 매력인가
- ⭐ **한국어 공식 사이트 + 메뉴판** (madamelan.vn/kr)
- 🌳 콜로니얼풍 정원 + 강변 위치 = 사진 명소
- 🍴 반쎄오·짜조·반베오·미꽝 등 **중부 정통 풀세트** 한 자리
- 🇰🇷 한국인 단골 No.1 = 시행착오 0
- 🧒 **야채 거부 아이용 볶음밥 별도 작은 접시** 제공

### 위치·이동·비용
| | |
|---|---|
| 📍 위치 | 4 Bạch Đằng, 한 강변 (시내 중심에서 도보 15분) |
| 🚐 푸라마에서 | 차 15분 (택시 20만동 ≈ 1만원) |
| 🚐 미카즈키에서 | 차 25분 |
| 💰 1인 비용 | **15~20만동** (한화 1~1.5만원) — 4인 가족 약 6만원 |
| 🕐 영업 | 06:30~22:00 |
| 📞 예약 | 한국어 사이트에서 가능 |

### 메뉴 추천 (가족 4인)
- 🥞 **반쎄오** (Bánh Xèo) — 강추, 직원 시연
- 🌯 **반베오** (Bánh Bèo) — 향신료 약함, 5세도 OK
- 🍜 **미꽝** (Mì Quảng) — 비빔국수, 향신료 약함
- 🍤 **짜조** (Nem rán) — 5세 무난
- 🍚 **새우볶음밥** — 음식 거부 5세 안전망

### 5세·9세에게는?
- ✅ **볶음밥 별도 접시** 제공 = 음식 거부 5세 1순위 안전
- ✅ 향신료 약하게 조절 가능 ("콩 쪼 라우 텀" = 고수 빼주세요)
- ✅ 메뉴판 한국어, 사진 풍부 → 9세도 직접 고름
- ✅ 에어컨 2층 좌석
- ⚠️ 1층 정원은 더울 수 있음 → **2층 예약**

### 가족 적합도 ★★★★★

**🟢 가야 하는 이유**
- **다낭 베트남식 입문 1순위** — 시행착오 없음
- 한국어 + 한국인 단골 + 음식 거부 5세 안전망(볶음밥)까지 다 갖춤
- 강변·콜로니얼 정원 = 부부 인생샷
- 한 자리에서 중부 정통 5종 시식 → 다른 베트남식당 갈 필요 줄어듦

**🟡 패스해도 되는 이유**
- 한국인 너무 많아 "현지" 분위기 X
- 가격 다른 로컬보다 1.5~2배
