## ☕ 4.1 Cong Caphe (콩카페 / Cộng Cà Phê)

> **코코넛 커피의 원조 — 베트남 카페 1순위**

![베트남 코코넛 커피](https://upload.wikimedia.org/wikipedia/commons/thumb/9/92/Vietnamese_coffee_with_milk_and_ice.jpg/960px-Vietnamese_coffee_with_milk_and_ice.jpg)

🥥 베트콩 군복 컨셉의 빈티지 인테리어 + 코코넛 커피 시그니처. 한국 연남동에도 진출했지만, 본가에서 마시는 코코넛 스무디 커피가 아내·아이가 가장 익숙한 베트남 맛.

### 무엇이 매력인가
- 🥥 **코코넛 밀크 커피 원조** (59,000동 ≈ 3,500원)
- 🇻🇳 베트남 사회주의·군복 컨셉 — 비주얼 한 컷
- 📍 **다낭에만 4지점** (박당, 리뜨쫑, 미케, 안뜨엉)
- 🧒 코코넛 스무디는 어린이용 음료 그대로 — 5세도 좋아함

### 위치·이동·비용
| | |
|---|---|
| 📍 1호점 | 96-98 Bạch Đằng (한강뷰) |
| 📍 4호점 | 안뜨엉, 미케비치 도보 |
| 🚐 푸라마에서 | 차 10~15분 (4호점) |
| 💰 음료 | 5만~7만동 (2,500~3,500원) |
| ⏱️ 영업 | 07:00~23:30 |

### 5세·9세에게는?
- ✅ **코코넛 스무디 = 디저트 음료** → 음식 거부 5세 안전망
- ✅ 매장 깨끗, 에어컨, 화장실 OK
- ⚠️ 박당 1호점은 좁고 항상 만석 → 안뜨엉 4호점 추천

### 가족 적합도 ★★★★

**🟢 가야 하는 이유**
- 다낭 카페 인생 음료 1순위, **안 가면 후회**
- 안뜨엉 4호점 = 푸라마에서 가깝고 야외 좌석
- 한국인이 가장 많이 검증한 곳

**🟡 패스해도 되는 이유**
- 한국에 매장 있음 (귀국 후 가능)
- 박당 지점은 사람 너무 많음
- 신선도·맛은 The Local Beans·Cua Ngo가 더 호평

### 한국인 후기
> "한강이 바로 보이는 뷰가 좋고 인테리어도 예쁜 콩카페" — 트립쿠폰 매거진 [출처](https://www.tripcoupon.com/hot-spot-view.php?idx=51)

> "베트남 로부스타 원두의 진한 쓴맛과 코코넛 크림의 부드럽고 달콤한 맛이 완벽한 조화." — 베트남 가이드 [출처](https://vietnamguide.co.kr/다낭-콩카페-메뉴-위치-가격-추천/)

> "탁 트인 야외 테라스에 앉아 시원한 바닷바람을 맞으며 커피를 마시는 것이 포인트 (4호점)" — 트립스토어 블로그 [출처](https://www.tripstore.kr/blog/다낭-콩-카페-메뉴-지점-비교)

## ☕ 4.2 XLIII Coffee (구 43 Factory) ⭐ 어른용

> **다낭 1순위 스페셜티 커피 — 정적·미니멀**

![베트남 드립 커피](https://upload.wikimedia.org/wikipedia/commons/thumb/5/52/VN_drip_coffee_on_table.jpg/960px-VN_drip_coffee_on_table.jpg)

☕ 콘크리트 미니멀 건축 + 작은 연못 + 천장 높은 갤러리 같은 공간. 다낭에서 보기 드문 **싱글 오리진 핸드드립**. 가격은 한국 수준, 분위기는 도쿄 블루보틀급. 커피 좋아하는 어른용.

### 무엇이 매력인가
- ☕ **다낭 스페셜티 1순위** (트립어드바이저 다낭 카페 Top 3)
- 🏛️ 미니멀 콘크리트 + 유리 + 연못 = 갤러리 분위기
- 🫘 산지 명확한 핸드드립 (에티오피아·콜롬비아 등)
- 🤫 정적·고요 — 책 읽기·사진 작업에 최적

### 위치·이동·비용
| | |
|---|---|
| 📍 위치 | 422 Đường 2 Tháng 9, Hai Chau |
| 🚐 푸라마에서 | **차 8~10분** |
| 🚐 미카즈키에서 | 차 25분 |
| 💰 핸드드립 | 9만~15만동 (5,000~8,500원) |
| ⏱️ 베스트 시간 | 오전 8~10시 (한적) |

### 5세·9세에게는?
- ⚠️ **정적·고요한 분위기** = 5세 통제 어려움
- ⚠️ 키즈 메뉴 ❌, 디저트 거의 없음
- 🚫 5세 적합도 △ — 어른 단독 추천

### 가족 적합도 ★★★ (어른용)

**🟢 가야 하는 이유**
- **부부 둘만 30분 도망** = 9세에게 호텔 풀, 5세 그랩으로
- 아내 카페 트렌드 = "와봤다" 인증 가치 ★★★★★
- 오전 일찍 = 한산, 이동 부담 적음

**🟡 패스해도 되는 이유**
- 5세 동반 어려움 (조용한 카페)
- 가격 한국 수준 = 가성비 ❌
- 더 캐주얼한 Wonderlust·The Local Beans로 대체 가능

### 한국인 후기
> "다낭에선 보기 드문 전문적인 필터 커피를 만날 수 있어요." — 트리플 가이드 [출처](https://triple.guide/articles/2d221e59-aa1c-4a47-9d77-93167f12d29c)

## ☕ 4.3 Highlands Coffee (하이랜드 커피)

> **베트남 스타벅스 — 시내 10곳+, 가성비 최고**

![다낭 하이랜드 커피 플래그십](https://upload.wikimedia.org/wikipedia/commons/thumb/f/fb/Highlands_Coffee_%C4%90%C3%A0_N%E1%BA%B5ng_City.jpg/960px-Highlands_Coffee_%C4%90%C3%A0_N%E1%BA%B5ng_City.jpg)

🇻🇳 베트남 1등 커피 프랜차이즈 (300+ 매장). 한국의 빽다방·이디야 같은 위상. 다낭 시내 어디 가도 보이고, **한강·용다리 뷰** 매장도 있음. 가격 저렴 (음료 3,000~5,000원).

### 무엇이 매력인가
- 💰 **가성비 최고** (음료 4만~7만동)
- 📍 **다낭에 10곳 이상** — 한 시장·미케·박당
- 🌃 박당지점·미케지점 = 한강·바다뷰
- 🍵 **프린맥스 (피치티) 어린이도 좋아함**

### 위치·이동·비용
| | |
|---|---|
| 📍 박당 지점 | 한강뷰, 용다리 도보 |
| 📍 미케 지점 | 미케비치 정면 2층 |
| 🚐 푸라마에서 | 차 15분 |
| 💰 음료 | 4만~7만동 (2,000~3,500원) |
| ⏱️ 영업 | 06:30~23:00 (지점별) |

### 5세·9세에게는?
- ✅ 프린맥스 (피치 그린티) = 5세도 인기
- ✅ 매장 넓고 에어컨 강함, 화장실 OK
- ✅ 케이크·파스트리도 풍부

### 가족 적합도 ★★★★

**🟢 가야 하는 이유**
- **5/23 용다리 불쇼 가는 길에 자동 묶임** (박당지점)
- 가성비 최고, 부담 없음
- 어디든 있어 일정 중 우연히 들르기 OK

**🟡 패스해도 되는 이유**
- 한국에 들어와도 비슷한 프랜차이즈 많음
- 콩카페·로컬 빈스가 시그니처에선 더 강함
- "와본 카페"라기보다 "쉬는 카페"

## ☕ 4.4 The Local Beans

> **다낭 코코넛 커피 베스트 (콩카페보다 진하다)**

![베트남 코코넛 커피](https://upload.wikimedia.org/wikipedia/commons/thumb/9/92/Vietnamese_coffee_with_milk_and_ice.jpg/960px-Vietnamese_coffee_with_milk_and_ice.jpg)

### 무엇이 매력인가
- ☕ **TripAdvisor 5.0/5.0** 다낭 카페 1위 (656/1524위 → 작은 공간이라)
- 🥥 **에스프레소 + 코코넛 스무디 분리 서빙** — 직접 부어 마시는 비주얼
- 🤫 한국인 적은 편 (콩카페와 차별화)

|---|---|

| 💰 음료 | 5만~7만동 |

## 🥥 4.5 The Coconut House

> **코코넛 디저트 + 커피 — "환장" 평이 5세도 OK**

![베트남 카페 분위기](https://upload.wikimedia.org/wikipedia/commons/thumb/e/e5/Long_Beach_Coffee_Bar_Da_Nang.JPG/960px-Long_Beach_Coffee_Bar_Da_Nang.JPG)

🥥 코코넛 디저트 (코코넛 푸딩·아이스크림·셔벗) + 커피의 조합. 다낭 시내에 위치하며, 한국 블로거들 사이에서 "코코넛 좋아하면 환장하는 곳"이라는 평. 5세도 코코넛 디저트 = **거부 가능성 매우 낮음**.

### 무엇이 매력인가
- 🥥 **코코넛 디저트 다양** (셔벗·푸딩·아이스크림·코코넛 잭)
- 🍦 5세 음식 거부 → **디저트는 거부 0순위**
- 📸 코코넛 잘라 그대로 담은 비주얼
- 💰 1만~3만동 디저트, 부담 없음

### 위치·이동·비용
| | |
|---|---|
| 📍 위치 | 다낭 시내 한강 인근 |
| 🚐 푸라마에서 | 차 12~15분 |
| 💰 디저트 | 3만~7만동 |
| ⏱️ 영업 | 09:00~22:00 |

### 5세·9세에게는?
- ✅ **음식 거부 5세에게 = 디저트는 안전망 100%**
- ✅ 코코넛 셔벗·아이스크림 = 한낮 무더위 회피
- ✅ 비주얼 인스타 = 9세 사진 관심

### 가족 적합도 ★★★★★

**🟢 가야 하는 이유**
- "환장" 평가 = 한국인 검증
- **5세 거부 안전망** = 점심 잘 안 먹은 날 디저트로 보충
- 가격 부담 없음, 가볍게

**🟡 패스해도 되는 이유**
- 시내 이동 필요 (푸라마에서 멀음)

![하이반 패스 산악 도로](https://upload.wikimedia.org/wikipedia/commons/thumb/a/ad/Da_Nang_Vietnam_-_H%E1%BA%A3i_V%C3%A2n_Pass_%282024%29_-_img_07.jpg/960px-Da_Nang_Vietnam_-_H%E1%BA%A3i_V%C3%A2n_Pass_%282024%29_-_img_07.jpg)

### 무엇이 매력인가
- 🐑 **양 떼와 직접 교감** = 5세·9세 인생 카페
- 🌄 **하이반 패스 정상 + 다낭 만 시티뷰**
- 💰 음료 2~3만동(1~2천원) = 가성비 충격
- 📸 초록 슬로프 + 흰 양 = 인스타·인생샷
- 🏯 **미카즈키 베이스에서 가장 가까운 산악 카페** (차 30분)

### 5세·9세에게는?
- ✅ **양 만지기·풀 주기 = 5세 흥분 1순위**
- ✅ 9세도 양과 사진 = 만족
- ✅ 음료 가격 부담 0
- ⚠️ **굽잇길 30분 = 5세 멀미** → 멀미약 필수
- ⚠️ 양 가까이 가면 약간 냄새 (화장실 시설 빈약)

### 가족 적합도 ★★★★

**🟢 가야 하는 이유**
- **미카즈키 베이스 5/21 반나절 드라이브 코스의 핵심**
- 양 + 시티뷰 + 가성비 = 4인 가족 모두 만족 드문 케이스
- **Lap An 라군 (1.7) 가는 길에 자연 정차** = 일정 효율
- 5세에게 동물 체험 = 평생 추억

**🟡 패스해도 되는 이유**
- 미카즈키→푸라마 이동 후엔 멀어짐 (5/22 이후 비추)
- 굽잇길 멀미 = 5세 짜증 위험
- 화장실·식당 시설 빈약
- 5월 우기 시작 → 비 오면 양 안 보임

### 함께 묶기 좋은 곳
- 🌅 **Lap An 라군** (1.7) — 하이반 너머, 차 20분
- 🐑 **양농장 카페 → 라군 → 굴구이 점심** = 미카즈키 5/21 반나절 풀코스
