## 👗 3.1 아오자이 입고 사진 (호이안 올드타운)

> **베트남 전통의상 + 노란 벽 골목 = 가족 인생샷**

![호이안 올드타운 아오자이 포즈](https://upload.wikimedia.org/wikipedia/commons/thumb/0/04/Hanhdeptrai242-hoi-an-da-nang-2024.jpg/960px-Hanhdeptrai242-hoi-an-da-nang-2024.jpg)

👗 호이안 올드타운에 줄지어 있는 아오자이 대여점. 여성·남성·아동 사이즈가 모두 구비되어 있고, 옷만 빌려 셀프 촬영도 / 작가 동행 스냅 패키지도 가능. 노란 벽·내원교·등불 골목이 모두 도보 5분 이내라 **30분 만에 인생샷 완성**.

![아오자이 입은 베트남 여성](https://upload.wikimedia.org/wikipedia/commons/thumb/c/cb/Vietnamese_girl_wearing_ao_dai_3.jpg/960px-Vietnamese_girl_wearing_ao_dai_3.jpg)

### 무엇이 매력인가
- 👗 **150개+ 아오자이 비치** (성인·아동·남성)
- 📸 노란 벽·내원교·등불 골목 = **올드타운 자체가 스튜디오**
- 👨‍👩‍👧‍👧 **5세도 입을 수 있는 아동 사이즈** 보유 매장 다수
- ⏱️ 옷 갈아입고 사진까지 **1~2시간** 내 끝남

### 위치·이동·비용
| | |
|---|---|
| 📍 위치 | 호이안 올드타운 |
| 🚐 푸라마에서 | 차 25~30분 |
| 💰 옷만 대여 (셀프) | 1벌 6~10만동 (3~5천원) |
| 💰 작가 스냅 패키지 | **4인 6~8만원** (옷 포함, 보정본 20장+) |
| ⚠️ 보증금 | 옷 손상·얼룩 시 패널티 30만동 |
| ⏱️ 소요 | 1~2시간 |

### 베스트 시간대 (5월)
| 시간 | 추천도 | 이유 |
|---|---|---|
| 16:30~18:30 | ⭐⭐⭐⭐⭐ | **골든아워** 일몰빛, 시원 |
| 09:00~10:30 | ⭐⭐⭐⭐ | 한적, 사람 적음 |
| 11:00~16:00 | ❌ | 무더위, 아오자이 안에 땀범벅 |
| 18:30~20:00 | ⭐⭐⭐⭐ | 등불 켜진 후 야경 |

### 5세·9세에게는?
- ✅ **5세 딸 = 미니 아오자이** (체험 결정타)
- ✅ 9세는 색·디자인 직접 고르는 재미
- ⚠️ 한낮은 더위로 5세 짜증 위험 → 늦은 오후 강추
- ⚠️ 옷이 길어서 **계단·턱 조심** (특히 5세)
- ⚠️ 음식·아이스크림 → 얼룩 = 패널티 → **사진 후 식사**

### 가족 적합도 ★★★★★

**🟢 가야 하는 이유**
- 호이안 일정에 **자연 결합** (5/22 또는 5/23)
- 5세·9세 자매가 노란벽 앞 = **여행 베스트 사진 1순위**
- 부부도 같이 입으면 **결혼 후 가족사진 다시 찍는 효과**
- 6~8만원 = 평생 가는 사진 가성비 ◎

**🟡 패스해도 되는 이유**
- 5월 한낮 더위 = 옷 안에서 5세 짜증날 수 있음
- 작가 스냅은 시간 약속 = 일정 묶임
- 셀프 대여만으로도 충분히 가능

### 함께 묶기 좋은 곳

- 🍜 **호이안 맛집** — 사진 끝나고 옷 반납 후
- 🏛️ **내원교·복권회관** — 도보권 포토스팟

### 한국인 후기

## 🏮 3.2 호이안 등불 만들기

> **3세부터 가능, 한국까지 가져갈 수 있는 손수 만든 기념품**

![호이안 등불](https://upload.wikimedia.org/wikipedia/commons/c/cf/Hoi_An_lanterns.jpg)

🏮 호이안의 상징인 비단 등불을 직접 만드는 1.5시간 워크숍. 대나무 살을 잡고 천을 입히는 과정을 강사가 1:1로 도와줌. **접이식으로 제작**되어 캐리어에 그대로 들어감 = 한국까지 안전하게 가져옴.

![호이안 등불 야경](https://upload.wikimedia.org/wikipedia/commons/2/28/Hoi_An_lanterns_at_night.jpg)

### 무엇이 매력인가
- 🎁 **직접 만든 등불 = 평생 기념품** (한국 집에 걸기)
- 👶 **3세부터 가능** = 5세도 강사 도움으로 완성
- 🏠 실내·에어컨 = 햇볕·더위 회피 ◎
- 📐 접이식 → **캐리어에 무리 없이 수납**

### 위치·이동·비용
| | |
|---|---|
| 📍 위치 | 호이안 올드타운 인근 (Maison Fleur, Lantern Lady, Happy Smile 등) |
| 🚐 푸라마에서 | 차 25~30분 |
| 💰 비용 | **1인 1~2만원** (4인 ≈ 6만원) |
| ⏱️ 소요 | 1.5시간 (익스프레스는 45분) |

### 5세·9세에게는?
- ✅ **9세 = 거의 혼자 완성**, 자부심 ↑
- ✅ **5세 = 강사 도움 필요**, 그래도 "내가 만들었다" 경험
- ✅ 실내·에어컨 = 한낮 더위 피난처로도 활용
- ⚠️ 5세는 30~40분 후 집중력 하락 → **익스프레스(45분) 추천**

### 가족 적합도 ★★★★

**🟢 가야 하는 이유**
- **음식 거부 5세**도 손작업은 곧잘 함 (검증된 패턴)
- 한국 가서도 매일 보는 **만질 수 있는 추억**
- 한낮(11~14시) 더위 회피용 실내 활동
- 가격 부담 ❌

**🟡 패스해도 되는 이유**
- 5세는 1.5시간이 길어서 후반 짜증 가능
- 작가 스냅·소원배 등 **다른 야간 일정과 충돌**할 수 있음
- 등불은 호이안 시장에서 완제품 만동에 살 수도 있음

### 함께 묶기 좋은 곳
- 👗 **아오자이 사진** (3.1) — 같은 올드타운
- 🌃 **호이안 야경 + 소원배** (3.3) — 늦은 오후 묶음

### 한국인 후기
> "강사들은 매우 친절하고 인내심 있어 5살 아이도 완성할 수 있었다." — 트립어드바이저 후기 (2025) [출처](https://www.tripadvisor.com/Attraction_Review-g298082-d9883197-Reviews-The_Lantern_Lady_Lantern_Making_Workshops-Hoi_An_Quang_Nam_Province.html)

> "익스프레스 45분 / 풀 1.5시간. 접이식으로 만들어 캐리어에 가져갈 수 있어요." — 메종플뢰르 호이안 [출처](https://www.maisonfleurhoian.com/en/product-page/lantern-making-class)

## 🕯️ 3.3 소원배 + 양초 띄우기 (호이안 야간 투본강) ⭐

> **호이안 가면 무조건 = 정찰제·짧고 강렬·5세 베스트**

![투본강 소원배 야경](https://upload.wikimedia.org/wikipedia/commons/thumb/c/cc/Boats_with_lanterns_on_the_Thu_Bon_river_IMG_3864.jpg/960px-Boats_with_lanterns_on_the_Thu_Bon_river_IMG_3864.jpg)

🌃 해 진 후 호이안 호아이강(투본강 본류)에 나무배를 띄우고, 손에 든 종이 등 양초를 강에 흘려보내는 **20분간의 마법**. 강 위로 수십 척의 배가 등불을 밝히고 떠가는 풍경 자체가 호이안 시그니처.

![호이안 풀문 페스티벌](https://upload.wikimedia.org/wikipedia/commons/thumb/7/78/Hoi_An_Full_Moon_Festival.jpg/960px-Hoi_An_Full_Moon_Festival.jpg)

### 무엇이 매력인가
- 🎫 **시 정찰제** = 사기·바가지 ❌ (2024년 도입)
- ⏱️ **20분 = 5세 집중력 안에서 끝남**
- 💰 **4인 11만동(약 6천원)** = 가성비 압도적
- 🌅 **매직아워(17:30~18:30)** 사진 = 인생 야경

### 위치·이동·비용
| | |
|---|---|
| 📍 위치 | 호이안 올드타운, 호아이강 매표소 |
| 🚐 푸라마에서 | 차 25~30분 |
| 💰 배 1척 (4인) | 1-3명 15만동, **4-5명 20만동** (1.1만원) |
| 💰 소원초 | 개당 1만동 (5천원, 4개면 4만동) |
| 🕐 운영 | 매일 16:30~21:30 (입장마감 21:00) |
| ⏱️ 소요 | **승선 20분** (대기 포함 30~40분) |

### 베스트 시간대
| 시간 | 추천도 | 이유 |
|---|---|---|
| 17:30~18:30 | ⭐⭐⭐⭐⭐ | **매직아워**, 노을+등불 |
| 18:30~20:00 | ⭐⭐⭐⭐ | 완전 야경, 가장 붐빔 |

### 5세·9세에게는?

- ✅ 양초 직접 강에 띄우는 **손동작 = 5세 만족**
- ✅ 구명조끼 제공
- ⚠️ 어두움 → 부모가 5세 손 꽉 잡기

### 가족 적합도 ★★★★★

- 정찰제 + 짧음 + 가성비 = 일정 부담 0

**🟡 패스해도 되는 이유**
- 따로 결정 안 해도 호이안 가면 자동으로 됨
- 사람 많아 줄 30분~ 가능

## 🛶 3.4 Cam Thanh 코코넛 마을 바구니배 ⭐

> **5세 검증, 구명조끼 필수, 호이안 가면 무조건**

![바구니배와 대나무 숲](https://upload.wikimedia.org/wikipedia/commons/thumb/8/82/Basket_Boat_and_the_Bamboo_forest_%28Unsplash%29.jpg/960px-Basket_Boat_and_the_Bamboo_forest_%28Unsplash%29.jpg)

🛶 호이안 올드타운에서 차 10분, **깜탄 코코넛 야자숲** 사이 좁은 수로에서 대나무로 만든 둥근 바구니배(Thuyen Thung)를 타는 체험. 사공이 직접 노 저으며 야자수 사이를 누비고, 운이 좋으면 어부의 그물 시범 / 코코넛배 묘기 쇼까지 관람.

![다낭 어촌의 코라클 보트](https://upload.wikimedia.org/wikipedia/commons/thumb/3/36/Coracles_in_Da_Nang_3.jpg/960px-Coracles_in_Da_Nang_3.jpg)

### 무엇이 매력인가
- 🛶 **세계 어디에도 없는 둥근 배**
- 🥥 야자숲 + 강 = 메콩 미니버전
- 🦺 **구명조끼 필수 착용** = 5세 안전 보장
- 🎪 어부 그물 + 코코넛배 묘기 쇼

### 위치·이동·비용
| | |
|---|---|
| 📍 위치 | 호이안 동쪽 깜탄(Cam Thanh) 마을 |
| 🚐 푸라마에서 | 차 25~30분 |
| 💰 입장 | 1인 5만동 (3천원) |
| 💰 바구니배 (1팀) | **8~10만원** (왕복차량+패키지) |
| 💰 셀프 (현장) | 성인 5달러, 2인 8달러 |
| ⏱️ 소요 | 30~45분 승선 (총 1시간) |

### 어린이 요금 정보
- 🆓 **신장 99cm 이하 = 무료** (5세 딸 평균 신장 110cm = 유료 가능)
- 🎫 신장 100cm 이상 = 성인과 동일 요금

### 5세·9세에게는?
- ✅ **구명조끼 + 평온한 강** = 안전 검증
- ✅ 5세도 30~40분 끝까지 즐김
- ✅ 베트남 전통 모자(농) 배 위에서 제공
- ⚠️ **덥고 습함** → 모자·선크림 필수

### 가족 적합도 ★★★★★

**🟢 가야 하는 이유**

- 구명조끼 + 사공 = 부부 운영 부담 0

## 🌿 3.5 Tra Que 채소마을 농사 체험

> **2024 UN 세계 최고 관광마을 — 농부복+물주기+물소+허브 체험**

![짜꿰 채소마을](https://upload.wikimedia.org/wikipedia/commons/thumb/0/00/Vegetables_in_Tr%C3%A0_Qu%E1%BA%BF_1.jpg/960px-Vegetables_in_Tr%C3%A0_Qu%E1%BA%BF_1.jpg)

- ✅ **5세 = 무료**, 1.4m 미만이면 OK
- ✅ **앉아만 있으면 끝** = 부부 체력 부담 0
- ✅ 시각·소리 자극 풍부 = 5세 집중력 유지 가능
- ⚠️ 9세 = 베트남어 자막은 못 읽음 → **시각 위주로 즐김**
- ⚠️ 야외 = 우천 시 진행 여부 확인

### 가족 적합도 ★★★★

**🟢 가야 하는 이유**
- **앉아 보는 = 부부 체력 + 5세 모두 OK**
- 5세 무료 = 4인 가족도 9~12만원
- 야경 + 다리 + 쇼 = **5/23 호이안 풀코스 마무리**
- 음식 거부 5세도 시각 자극엔 만족

**🟡 패스해도 되는 이유**
- 쇼 19:30 = **5세에 늦은 시간** (귀가 후 22시)
- 베트남 역사 = 9세 이해도 한계
- 소원배(3.3)와 같은 야간 = **충돌**, 둘 중 하나만
- 야외 쇼 → 우기·돌풍 시 취소
