## 🌅 1.1 미케 비치 (My Khe Beach / Bãi biển Mỹ Khê)

> **세계 6대 해변, 다낭의 얼굴**

![미케 비치](https://upload.wikimedia.org/wikipedia/commons/c/c0/My_Khe_Beach%2C_Da_Nang%2C_Vietnam.jpg)

🏖️ 끝없이 길게 뻗은 황금빛 모래사장. 일출 시간이면 어선들이 출항하는 실루엣이 바다 가득. 한국 부산 광안리를 넓고 잔잔하게 만든 느낌.

![미케비치 어부와 바구니배](https://upload.wikimedia.org/wikipedia/commons/e/ec/Fishermen_on_My_Khe_Beach.jpg)

### 무엇이 매력인가
- ⭐ **포브스 선정 세계 6대 매혹적 해변**
- 🌅 **일출 명소** — 어선·야자수·황금빛 모래
- 🌊 **5월 수온 28℃**, 파도 비교적 잔잔
- 📸 인스타·블로그 사진 1순위 다낭 명소

### 위치·이동·비용
| | |
|---|---|
| 📍 위치 | 다낭 시내 동쪽, 한강 너머 |
| 🚐 푸라마에서 | **차 10분** (택시 12~15만동) |
| 🚐 미카즈키에서 | 차 25~30분 |
| 💰 입장 | **무료** |
| 🛋️ 선베드 | 5~10만동/일 (3~5천원) |
| ⏱️ 소요 | 1~2시간 산책 |

### 베스트 시간대 (5월 기준)
| 시간 | 추천도 | 이유 |
|---|---|---|
| 05:30~07:30 | ⭐⭐⭐⭐⭐ | 일출 인생샷, 시원, 어선 |
| 07:30~10:00 | ⭐⭐⭐⭐ | 가족 산책 |
| 10:00~16:00 | ❌ | 모래 발화상급, UV 7~10 |
| 16:30~18:30 | ⭐⭐⭐⭐⭐ | 일몰 산책, 시원 |
| 18:30~ | ⭐⭐⭐ | 야간 조명, 노점 |

### 5세·9세에게는?
- ✅ 모래 놀이, 발목 깊이 물놀이 OK
- ✅ 5월은 해파리 적음, 수온 적당
- ⚠️ **빨간 깃발 구역 절대 X**, **노란 깃발 + 안전요원 시야**
- ⚠️ 한낮 모래 발화상급 → 아쿠아슈즈 필수
- ⚠️ 이안류 사고 종종 발생 → 깊이 안 들어가기

### 가족 적합도 ★★★★★

**🟢 가야 하는 이유**
- 푸라마 도보권. **이른 새벽·늦은 오후 산책 = 일정 부담 0**
- 일출 어선 사진 = 부부+9세 인생샷
- 한국에서 보기 어려운 황금빛 + 야자수 풍경

**🟡 패스해도 되는 이유**
- 호텔 앞 **논누억 비치(1.2)** 가 더 한적·고급
- 미케는 인기 명소라 사람 많음 (특히 한국인 단체)

### 함께 묶기 좋은 곳
- 🥩 **골든미트하우스** (도보 3분, 한식 BBQ) — 일몰 후 저녁
- 🛕 **린응 사원** (차 15분 북쪽) — 시내 가는 길에
- ☕ **Cua Ngo Cafe** (차 5분, 모로코 컨셉)

### 한국인 후기
> "해변가다 보니 정말 아이들이 마구 뛰어 놀 수 있고 산책하며 걸었는데 너무 좋더라구요. 모래도 너무 깨끗했어요." — 트립닷컴 모먼트 (2024) [출처](https://kr.trip.com/moments/detail/da-nang-669-134275934/)

> "세계 6대 해변으로 꼽히는 미케비치의 고운 모래는 아이들의 거대한 모래놀이터가 되어줘요." — 트립스토어 블로그 (2025) [출처](https://www.tripstore.kr/blog/4월-다낭-날씨-아이와-호캉스)

## 🏝️ 1.2 논누억 비치 (Non Nuoc Beach / Bãi biển Non Nước)

> **푸라마 앞 한적·고급 해변** — 호텔 자동 포함

![논누억 비치 바구니배](https://upload.wikimedia.org/wikipedia/commons/1/1b/Non_nuoc_Basket_boats.jpg)

🏖️ 미케보다 한적하고 모래는 더 곱다. 푸라마·메리어트가 면해 있어 5성 리조트 손님 위주. 오행산이 바로 뒤에 있어 산+해변 조망.

![논누억 리조트 풍경](https://upload.wikimedia.org/wikipedia/commons/5/5b/Resort_development_at_Non_Nuoc.jpg)

### 무엇이 매력인가
- 🤫 미케 대비 **사람 적고 조용함**
- 🌊 **파도 잔잔** → 5세에 더 안전
- 🏨 푸라마 투숙객 → 선베드·타올 무료
- 🏔️ 뒤로 오행산 봉우리가 보이는 풍경

### 위치·이동·비용
| | |
|---|---|
| 📍 위치 | 다낭 남쪽, 오행산 인근 |
| 🚐 푸라마에서 | **도보 0분** |
| 💰 비용 | **무료** (호텔 비치) |
| ⏱️ 소요 | 호텔 일정 중 수시 |

### 5세·9세에게는?
- ✅ 미케보다 잔잔, 5세 안전
- ✅ 호텔 풀과 모래 놀이 자유 전환
- ✅ 호텔 시설 즉시 이용 (화장실, 음료)

### 가족 적합도 ★★★★★

**🟢 자동 포함** — 푸라마 2박(5/22~24) 동안 자동 활용. **별도 결정 필요 ❌**

### 한국인 후기
> "바다가 보이는 메인풀은 규모도 크고 바로 앞에 미케비치(논누억 북쪽 연결)로 이어져 있어서 뷰, 개방감이 장난이 아닙니다." — 브런치 (2024) [출처](https://brunch.co.kr/@whatsinmytrip/23)

> "한쪽엔 수영장, 한쪽엔 바다가 보이는데 호캉스 그 자체가 따로 없습니다." — 브런치 (2024)

> "다낭 남부 논누억 비치 일대에는 프라이빗하고 럭셔리한 숙소가 모여 있어 호젓하고 낭만적." — 한국경제 (2024.12) [출처](https://www.hankyung.com/article/202412028524K)

> "야자수와 파라솔 아래 선베드에 누워 있으면 시간 가는 줄 모릅니다." — 브런치 (2024)

## 🐟 1.3 남오 비치 (Nam O Beach / Bãi biển Nam Ô)

> **미카즈키 인근 어촌 + 일몰 명소** (한국인 거의 없음)

![다낭 어촌의 코라클 보트](https://upload.wikimedia.org/wikipedia/commons/5/5c/Coracles_in_Da_Nang_1.jpg)

🏖️ 베트남 최고급 액젓(느억맘) 산지인 **남오 마을**의 해변. 관광지화 안 됨, 어선과 바위와 야자수가 있는 **빈티지·로컬 어촌 풍경**. 일몰이 서쪽 산자락 너머로 떨어지는 다낭 몇 안 되는 일몰 포인트.

![다낭 북부 어촌](https://upload.wikimedia.org/wikipedia/commons/3/36/Coracles_in_Da_Nang_3.jpg)

### 무엇이 매력인가
- 🌅 **다낭 일몰 명소 Top 3** (서쪽이라 해 떨어짐)
- 🐟 베트남 최고급 액젓 산지 (Nam O 느억맘)
- 🪨 **남오 암초(Rạn Nam Ô)** — 썰물 때 녹색 이끼 바위
- 🤫 **한국인 거의 없음** = 한적
- 📸 빈티지·필름 톤 인스타 사진

### 위치·이동·비용
| | |
|---|---|
| 📍 위치 | 다낭 북서, 하이반패스 기슭 |
| 🚐 미카즈키에서 | **도보 10~15분 / 차 5분** |
| 🚐 푸라마에서 | 차 30분+ (먼 편) |
| 💰 비용 | **무료** |
| ⏱️ 소요 | 30~45분 |

### 베스트 시간대
- 🌇 **17:30~18:30** 일몰 (5월)
- 그 외 시간엔 시설 빈약, 굳이 갈 필요 ❌

### 5세·9세에게는?
- ✅ 일몰 산책은 5세도 OK
- ⚠️ 시설 빈약, 화장실·카페 거의 없음
- ⚠️ **이끼 바위 미끄러움** → 운동화 필수

### 가족 적합도 ★★★★

**🟢 가야 하는 이유**
- **미카즈키 묵을 때 도보 10분** = 일정 부담 0
- 5월 일몰 18:10~18:20 — 워터파크 마치고 산책
- 한국 블로그에 잘 안 나옴 = 우리 가족만의 추억

**🟡 패스해도 되는 이유**
- 미카즈키 호텔 풀에서 일몰도 충분히 보임
- 시설 빈약 → 5세 화장실 가고 싶으면 곤란

### 한국인 후기
> "남오 암초(Rạn Nam Ô)는 미케 비치와 완전히 다른 분위기. 다낭 시내에서 17km 떨어진 리엔찌에우." — payd.vn 한국어 [출처](https://payd.vn/ko/blogs/trai-nghiem-cac-bai-bien-dep-o-da-nang-kor)

> "녹색 이끼로 뒤덮인 바위가 펼쳐지는 풍경. 썰물 때 가야 진짜 모습을 볼 수 있어요." — Senior World 가이드 (2025) [출처](https://seniworld.com/nam-o-beach/)

> "방문 후 남오식 생선 샐러드(gỏi cá)는 꼭 먹어보세요. 400년 역사의 어촌 마을입니다." — payd.vn

> "다낭 시내에서 30~45분 거리. 입장료 무료, 차량 주차도 가능해 가족 방문 좋아요. 단, 이끼 바위는 미끄러워 운동화 필수." — Airial Travel (2025) [출처](https://www.airial.travel/attractions/vietnam/nam-o-reef-da-nang-DX3Dq4Rr)

## 🐒 1.4 손짜 반도 드라이브 (Son Tra Peninsula)

> **"원숭이산" + 67m 관음상**

![손짜반도 전경](https://upload.wikimedia.org/wikipedia/commons/8/8d/Ban_dao_Son_Tra.jpg)

🏔️ 다낭 동쪽 거대한 반도. 해발 700m 산이 반도 전체를 덮고 있고, 중턱에 **린응 사원**이 있음. 정상 부근은 야생 원숭이가 출몰하는 산림보호구역.

![손짜산에서 본 다낭 만 전경](https://upload.wikimedia.org/wikipedia/commons/f/f8/Da_Nang_Bay_seen_from_the_Son_Tra_Mountain.jpg)

### 무엇이 매력인가
- 🏔️ 다낭 시내·미케 비치 한눈에
- 🐒 야생 원숭이 (운 좋으면)
- 🌅 정상 전망대에서 일몰
- 📸 굽이굽이 산길 드라이브 풍경

### 위치·이동·비용
| | |
|---|---|
| 📍 위치 | 다낭 동쪽 끝 반도 |
| 🚐 푸라마에서 | 차 25분 |
| 🚐 미카즈키에서 | 차 30분 |
| 🚐 이동 수단 | **택시·그랩카 / 한국어 단독차량** (오토바이 ❌) |
| 💰 비용 | 무료, 차량비만 |
| ⏱️ 소요 | 반나절 (린응사 묶음) |

### ⚠️ 5세 멀미 위험
- **굽이굽이 산길** — 멀미약 필수
- 차에 앉아만 있다면 OK, 단 1~1.5시간 차량 시간

### 가족 적합도 ★★★

**🟢 가야 하는 이유**
- **린응사와 묶음** = 사실상 같은 코스
- 다낭 시내 파노라마 = 9세에게 인상적
- 단독 차량으로 편하게

**🟡 패스해도 되는 이유**
- 린응사만 가도 충분 (정상까지 안 올라가도 됨)
- 5세 멀미 + 부부 체력 약함 = 굽잇길 부담
- 정상 전망대는 안개 자주 끼어 시야 ❌일 수도

### 한국인 후기
> "입구를 지나면 웅장한 67m 높이의 해수관음상이 한눈에 들어오는데, 맑은 하늘과 어우러진 모습이 정말 장관입니다." — 트립닷컴 모먼트 (2025) [출처](https://kr.trip.com/moments/detail/da-nang-669-141966400/)

> "단순한 사찰을 넘어, 다낭 해변과 시내를 동시에 내려다볼 수 있는 최고의 전망 포인트입니다." — 트립닷컴 모먼트 (2025)

> "야생 원숭이가 살고 있어 생태 교육에도 좋다. 단, 가방 뒤지거나 소지품 빼앗을 수 있으니 주의." — 다음 가족 가이드 [출처](https://m.view.nate.com/travel/view/373816/)

> "처음에는 웅장한 크기에 압도되었다. 다가갈수록 섬세한 조각 기술에 한 번 더 탄식이 나왔다." — 브런치 [출처](https://brunch.co.kr/@hsgee07125jyc/1)

> "추천 시간은 해 질 무렵 — 노을과 바다 전망이 최고. 노출이 심한 복장은 피하는 게 좋아요." — 베트남가이드 (2025) [출처](https://vietnamguide.co.kr/다낭-린응사-불상-관광명소/)

## 🌴 1.5 An Bang Beach ⭐ (호이안 인근)

> **"베트남에서 가장 안전한 영유아 비치 중 하나"**

![안방 비치 (2024)](https://upload.wikimedia.org/wikipedia/commons/b/b0/2024-11-23_An_Bang_Beach_in_Hoi_An_in_November.jpg)

🏖️ 호이안 올드타운에서 차 10분 거리. 미케보다 **파도 약하고 한적하며**, 비치 라인을 따라 외국인 익스팻이 운영하는 **부티크 비치카페·풀**이 있음. 가족 동반 외국인이 가장 사랑하는 베트남 중부 비치.

![안방 비치 풍경](https://upload.wikimedia.org/wikipedia/commons/4/40/Playa_An_Bang%2C_Hoi_An%2C_Vietnam_%2839510560665%29.jpg)

### 무엇이 매력인가
- 🌊 **파도 매우 잔잔** → 5세 영유아 친화 검증
- ☕ **The DeckHouse·SoulKitchen·La Plage** 등 비치카페 풍부
- 🤫 한국인 거의 없음 (외국인 거주자 위주)
- 🍝 비치카페에서 키즈 메뉴 + 양식 = 음식 거부 5세 안전

### 위치·이동·비용
| | |
|---|---|
| 📍 위치 | 호이안 올드타운 동쪽 5분 |
| 🚐 푸라마에서 | 차 25~30분 |
| 🚐 호이안 올드타운에서 | 택시 4 USD |
| 💰 비치 | **무료** (선베드는 카페 1잔 주문 시 무료) |
| 💰 비치카페 | The DeckHouse 점심 1인 1.5~3만원 |
| ⏱️ 소요 | 2~4시간 |

### 베스트 시간대
- 🏖️ **08:00~10:00** 일찍 아침
- ☕ **10:00~14:00** 비치카페 + 그늘
- 🌇 **16:30~18:00** 일몰

### 5세·9세에게는?
- ✅ "베트남에서 가장 안전한 영유아 비치" 평가
- ✅ The DeckHouse 풀 + 비치 + 키즈 메뉴 = 한 곳에서 다
- ✅ 비치카페 그늘 충분 → 햇볕 회피 가능
- ✅ 화장실·물놀이 시설·음식 모두 ◎

### 가족 적합도 ★★★★★

**🟢 가야 하는 이유**
- **호이안 야경 가는 김에 묶을 수 있음** (기존 5/23 일정 자연 확장)
- 5세에게 가장 안전한 비치
- 미케·논누억보다 한적·고급
- 비치카페에서 양식 점심 = 음식 거부 5세 안전망

**🟡 패스해도 되는 이유**
- 호텔 비치(논누억)로 충분
- 호이안 풀데이로 일정 늘어남 (현재 야간만)

## 🪨 1.6 Bai But / Bai Rang (손짜반도 숨은 코브)

> **손짜반도 동쪽 사면의 백사장·터키블루 코브**

![손짜반도 해변](https://upload.wikimedia.org/wikipedia/commons/8/8b/Bai_Bien_Tai_Quan_Son_Tra.jpg)

🏝️ 손짜반도 안쪽으로 들어가다 보이는 **잔잔한 만 형태의 작은 해변들**. 시설 거의 없는 자연 그대로의 코브. 반도 도로변에서 차로 잠시 멈추고 사진 찍는 정도.

### 무엇이 매력인가
- 🏖️ **터키블루 색의 잔잔한 만**
- 🤫 거의 무인 (현지인 피크닉)
- 🏔️ 산 배경 비치 풍경

### 위치·이동·비용
| | |
|---|---|
| 📍 위치 | 손짜반도 내부 |
| 🚐 푸라마에서 | 차 25분 (린응사 가는 길) |
| 💰 비용 | 무료 |
| ⏱️ 소요 | 사진 정차 5~15분 |

### 가족 적합도 ★★★

**🟢 가야 하는 이유**
- 손짜반도 가는 김에 5분 잠깐 정차
- 사진 한 컷

**🟡 패스해도 되는 이유**
- 시설 거의 없음 (화장실·그늘 ❌)
- 짧은 정차일 뿐 깊이 있는 경험 X
- **Bai But은 리조트 공사 부지 안이라 일반 공개는 제한적**
- 5세에게 별 의미 없음

### 후기
> "Bai But은 300m 길이 청정 해변. 어부들이 관음상을 발견해 사찰을 세웠다는 전설." — Hoi An Day Trip [출처](https://hoiandaytrip.com/son-tra-peninsula-beaches/)

> "Bai Rang은 작은 해변이지만 스노클링이 훌륭. 해양 생물이 가장 풍부한 자연 보호 구역." — Hoi An Day Trip

> "Bai But은 펜스로 출입 제한. 관음상 언덕에서 내려다보는 게 현실적인 방법." — Hoi An Day Trip

> ⚠️ 한국인 가족 후기는 거의 없음. 손짜반도 드라이브 중 차창 풍경 또는 린응사 전망대 조망으로 대체.

## 🪞 1.7 Lap An 라군 (Lap An Lagoon / Đầm Lập An)

> **800ha 거대 기수 라군 + 일몰 인스타 명소**

![랑꼬-랍안 라군](https://upload.wikimedia.org/wikipedia/commons/f/f0/Lang_Co_lagoon%2C_Lap_An_lagoon%2C_Vietnam.jpg)

🌅 다낭과 후에 사이, 하이반 패스를 넘어가면 만나는 **거대한 라군**. 일몰 시간에 간조면 **모래길이 드러나** 라군 한가운데를 걸을 수 있는 환상적 풍경. 굴 양식이 활발한 어촌이라 **굴구이 점심**도 유명.

![랍안 라군 굴 양식장](https://upload.wikimedia.org/wikipedia/commons/c/c1/Lap_An_lagoon_%2842920751850%29.jpg)

![랑꼬 라군 어선](https://upload.wikimedia.org/wikipedia/commons/5/52/Vietnamese_fishing_boats%2C_Lang_Co_lagoon%2C_Vietnam.jpg)

### 무엇이 매력인가
- 🌅 **베트남 인스타 일몰 핫스팟 Top 5**
- 🏝️ 간조 시 모래길 (Low tide walking path)
- 🦪 어부 보트 + 굴 양식 견학 + **굴구이 식사**
- 🛣️ 하이반 패스 드라이브와 자연 결합

### 위치·이동·비용
| | |
|---|---|
| 📍 위치 | 다낭 북쪽 29km, 하이반 너머 |
| 🚐 미카즈키에서 | **차 50분** (북쪽이라 미카즈키 베이스 유리) |
| 🚐 푸라마에서 | 차 1시간 10분 |
| 💰 비용 | 무료, 보트 투어 1인 약 5천원 |
| 🍴 굴구이 점심 | 1인 1~2만원 |
| ⏱️ 소요 | 반나절 |

### 베스트 시간대 & 시즌
- 🌇 **17:00~18:30 일몰** (5월 일몰 18:15)
- 📅 **4~9월 건기 적합**
- 🌧️ 우기엔 비추

### ⚠️ 주의
- **차량 1시간** — 5세 멀미 가능
- 하이반 패스 굽잇길 = 멀미 위험 ↑
- 화장실 빈약

### 가족 적합도 ★★★

**🟢 가야 하는 이유**
- **미카즈키 베이스 + 양 농장 카페(Hai Van Sheep Hill) + Lap An 묶음 = 반나절 인생 드라이브**
- 5월 일몰 라군 = 평생 한 번 사진
- 굴구이 점심 = 신선·로컬

**🟡 패스해도 되는 이유**
- 1시간 차량 + 하이반 굽잇길 = 5세에게 부담
- 시설 빈약 (화장실·카페)
- 일정 빡빡해짐
- 한국인 가족 후기 부족 (정보 제한적)

### 후기
> "다낭에서 후에 가는 길, 랍안 라군은 필수 정차 코스. 썰물 때 모래 길이 드러나 라군 한가운데를 걷는 느낌." — 63's Travel (2024) [출처](https://63stravel.com/ko/news/saegjo/lap-an-seoghoyi-pyeonghwaroun-areumdaum)

> "다낭 시내에서 약 29km, 후에에서 64km. 하이반 패스 직전 우회전 3km면 바로 보여요." — 다낭-후에 가이드 [출처](https://huetodanangbytrain.com/lap-an-lagoon/)

> "베트남 12개 주요 라군 중 하나. 굴 양식장이 많아 랑꼬 굴 요리도 함께 즐기기 좋아요." — 트리플 가이드 [출처](https://triple.guide/articles/6bb1f9e0-cfda-49af-a40b-7339b3a10ed6)

> ⚠️ 한국인 가족 후기 자체가 매우 적음. 트립닷컴 한국 페이지에 "아직 리뷰가 없습니다" 상태. 대부분 다낭→후에 이동 중 잠시 들리는 포토 스팟으로 다뤄짐.

## 🌃 1.8 한 강 산책로 (Han River Walk)

> **다낭 시내 야경 산책의 황금 동선**

![한강 한 다리 야경](https://upload.wikimedia.org/wikipedia/commons/4/4c/Han_River_Bridge_in_Vietnam_Night_View.jpg)

🌉 다낭을 가르는 한 강(서울 한강과 영문 표기 동일!)을 따라 양쪽으로 펼쳐진 **야간 산책로**. 강 위에 5개의 다리가 모두 컬러 LED로 빛나고, 시내 빌딩 야경이 강물에 반사. 평지 산책이라 부부 체력에 부담 없음.

![다낭 용다리](https://upload.wikimedia.org/wikipedia/commons/4/41/%C4%90%C3%A0_N%E1%BA%B5ng_Dragon_Bridge.jpg)

![박당 거리 (한강 서쪽 산책로)](https://upload.wikimedia.org/wikipedia/commons/f/f1/One_view_of_Bach_Dang_street%2C_Da_Nang%2C_Vietnam_-_Indochina_Riverside.jpg)

### 무엇이 매력인가
- 🌉 **5개 다리 야경** (용다리·트란티리·사랑의부두 등)
- 🌃 다낭 빅벤·시청 야간 조명
- 🚶 평지 산책 (체력 부담 0)
- 🌬️ **강바람 시원** (5월 더위 회피)

### 위치·이동·비용
| | |
|---|---|
| 📍 위치 | 다낭 시내 한가운데 |
| 🚐 푸라마에서 | 차 15분 |
| 🚐 미카즈키에서 | 차 25분 |
| 💰 비용 | **무료** |
| ⏱️ 소요 | 30~60분 산책 |

### 베스트 시간대
- 🌅 19:00~21:00 (조명 + 시원함)
- 🔥 **5/23 토 21:00 = 용다리 불쇼** (이미 일정 확정)

### 5세·9세에게는?
- ✅ 평지 산책, 안전
- ✅ 다리 조명 변화 = 시각적 자극
- ✅ 노점·아이스크림·음식 풍부

### 가족 적합도 ★★★★

**🟢 가야 하는 이유**
- **이미 5/23 용다리 불쇼 코스에 자동 포함**
- 산책하면서 자연스럽게 사랑의부두·APEC 파크 묶임
- 부부 체력에 부담 ❌

**🟡 별도 결정 불필요**
- 용다리 불쇼 가는 길에 자동 산책

### 한국인 후기
> "어둠이 내린 강변은 바람이 불어 시원해서 걷기 좋았다." — 브런치 (2024) [출처](https://brunch.co.kr/@renoir91/150)

> "반짝반짝 다리는 색색의 조명으로 빛났다. 강바람이 불어 시원하니 풍경은 아름답고!" — 브런치 (2024)

> "유명한 용다리도 보게 되었다. 다리 위로 기다란 용이 지나가는 것 같았다." — 브런치 (2024)

> "용다리는 매주 금·토·일 밤 9시 불쇼. 용 모양 조형물에서 실제 불과 물이 분사되는 10~15분 퍼포먼스." — 트립닷컴 다낭 가이드 (2025) [출처](https://kr.trip.com/blog/vietnam-danang-hoian-best/)
