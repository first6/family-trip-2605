# 바나힐 심층 리서치 (보존용 — 이번 여행에서 제외)

> 5세 + 9세 + 체력 약한 부부 조건에서 바나힐을 갈 수 있는지 다양한 시나리오로 검증한 결과.
> 최종 결정: **이번 여행은 패스**. 향후 7~8세 이상이 됐을 때 재시도 권장.

---

## 결론 요약

**갈 수 있는 유일한 방식**: 한국어 단독 가이드 + 차량 + 3~4시간 초압축 코스 (케이블카 + 골든브릿지 + 짧은 프랑스 마을 + 점심 + 하산). 그 외 시나리오(반나절·풀데이·조인 투어)는 5세에게 모두 비현실적.

---

## 핵심 수치 (사실 검증된 데이터)

### 도보 거리
- "케이블카 + 골든브릿지만" 코스 = **편도 400~600m, 왕복 800m~1.2km**, 순수 도보 30~45분
- "풀 코스" = **9~10km / 13,000보 이상** — 5세 절대 불가
- 골든브릿지 자체 길이: 150m, 폭 12.8m
- 마르세유역 → 골든브릿지: 100~250m, 도보 2~5분

### 시나리오별 평가

| 시나리오 | 도보 | 시간 | 5세 적합도 |
|---|---|---|---|
| A. 초압축 (케이블카+골든브릿지만) | ~1km | 3~4h | ★★★★ |
| B. 기본형 (+프랑스 마을+점심) | 2.5~4km | 5~6h | ★★ |
| C. 풀데이 (모든 명소) | 9~10km | 8~10h | ★ |
| D. 한국어 단독 + A 코스 | 1km | 4h | ★★★★★ |

### 비용 (4인 가족, 2026년)
- 입장료 성인: 1,000,000동 (≈5만원)
- 입장료 어린이 (100~140cm): 750,000동 (≈3.7만원)
- 입장료 어린이 100cm 미만: 무료
- 한국어 단독 가이드 + 차량: 1팀 약 30만원
- 4인 풀패키지 추정: **약 50~60만원** (점심 별도)

### 5월 환경
- 산정상 기온: 25~28℃ (다낭 시내 33~35℃보다 5~10℃ 낮음)
- 5월은 건기 끝물, 비교적 클리어
- 오후 스콜 가능성 → **오전 일정 필수**
- 골든브릿지 인파: 9시 이후 폭발, **8:30 이전 도착 필수**

---

## 운반 수단 (만약 갔을 경우)

### 외부 유모차 대여 (필수)
- VOVO 브랜드, 다낭 시내 호텔 무료 배달 (3~4km)
- 클룩, 마이리얼트립 사전 예약
- 24시간 전 무료 취소
- **케이블카에 접이식으로 탑승 가능**

### 힙시트 (한국에서 지참)
- 5세 18kg 안기용
- 일반 아기띠는 5세에 불편
- 에어메쉬 + UV차단

### 바나힐 무료 대여
- 휠체어: 매표소 옆 고객센터, 보증금 200만동 (10만원, 반납 시 환불), 선착순
- 트롤리 (유아용 카트): 무료 대여 가능 (수량 제한, 현장 확인)

## 만약 가는 경우 — 정확한 일정안

| 시간 | 활동 |
|---|---|
| 06:30 | 호텔 기상, 가벼운 조식 |
| 07:30 | 한국어 가이드 + 차량 호텔 픽업 |
| 08:15 | 바나힐 매표소 도착 (사전 QR 티켓) |
| 08:30 | 호이안역 4번선 케이블카 탑승 |
| 08:50 | 마르세유역 도착, 골든브릿지로 도보 |
| 09:00 | 골든브릿지 사진 30분 |
| 09:30 | 짧은 케이블카로 보르도/루브르역 |
| 09:45 | 프랑스 마을 광장 30~45분 |
| 10:30 | 광장 카페 휴식 |
| 11:00 | Four Seasons 뷔페 또는 라피카체 점심 |
| 12:00 | 케이블카 하산 |
| 12:30 | 차량 탑승, 호텔 복귀 |
| 13:30 | 호텔 도착, 풀/낮잠 |

총 체류 약 4시간, 도보 1.5~2km, 5세 안고 다닐 누적 거리 300~500m

---

## 절대 피해야 할 것
- 풀데이(8~10시간) 코스
- 조인 투어 (다른 가족과 합승) — 페이스 자유 없음
- 9~10시 사이 마르세유역 도착 — 인파 폭발
- 알파인 코스터에 5세 태우기 (110cm 미만 비탑승)
- 오후 14~17시 야외 일정 (스콜·인파)
- 입장료 아깝다고 풀데이로 늘리기 → 가족 전체 후회 확정

---

## 이번 여행에서 제외한 이유
1. 새벽 6:30 기상이 부부·아이에게 부담
2. 다른 일정(미카즈키 워터파크, 호이안 야경, 용다리 불쇼)만으로도 충분히 임팩트
3. 한 번 무리하면 다음날 가족 컨디션 다운 → 여유로운 여행 깨짐
4. 5세에게 너무 일러요. 7~8세 됐을 때 다시 와도 됨
